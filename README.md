## Programs

- **[Vault + Registration CPI](https://github.com/narsixyz/turbin3-vault-program)** - Anchor SOL vault whose `withdraw` performs a cross-program invocation into a separate registration program that writes a GitHub username on-chain. Deployed to devnet.
- **[solana_escrow](https://github.com/narsixyz/solana_escrow)** - Two Anchor programs in one crate: a personal PDA **Vault** (initialize / deposit / withdraw / close) and a SOL-for-SOL **Escrow** (lock funds for a claimant, or cancel and reclaim).
- **[Solana Programs Collection](https://github.com/narsixyz/solana-programs-collection)** - Programs built for learning and experimentation.
- **[Turbin3 Assignments](https://github.com/narsixyz/Turbin3_assignments)** - Turbin3 Solana Builder Bootcamp.
